Privacy policy

Pagelift privacy policy

Effective 5 October 2026. Applies to the Pagelift Chrome extension ("Pagelift — Capture"), the Pagelift Figma plugin, the Pagelift proxy and this website.

The short version

Pagelift doesn't collect, sell or share personal data. It has no accounts, no analytics and no tracking. Captures made with the Chrome extension never leave your computer. Pages imported by URL pass through our proxy so the plugin can read them, and the proxy doesn't keep them.

The Chrome extension

When you click Capture page, the extension reads the page in your current tab: its layout, text, styles, links and images. It does this only when you click, and only on that tab.

  • The capture is kept in the extension's memory until you copy it or download it as a .pagelift.json file. It is never sent to Enclave Studios or anyone else.
  • To include images, the extension downloads them from the websites that already serve them to you, the same way your browser does.
  • Closing the browser clears the capture from memory. Downloaded files stay where you saved them.

Why the extension asks for each permission

  • Access to the active tab and scripting: to read the page you choose to capture.
  • Debugger: only during a capture, to resize the page to tablet and mobile widths, switch dark mode on, and trigger hover states. Chrome shows a notice while this happens.
  • Access to all sites: so captures work on any website you choose, and so the page's images can be included.

The Figma plugin and URL import

When you import a capture file, the plugin reads that file and creates layers in your Figma file. Nothing is sent anywhere.

When you import by URL, the plugin asks the Pagelift proxy, which runs on Cloudflare, to fetch the page and its stylesheets, images and fonts. The proxy passes them back to the plugin and doesn't log or store them. Cloudflare may keep short-lived cache copies and standard request logs, such as IP addresses, under its own privacy policy. The plugin can't contact any other server, which Figma enforces.

This website

This site is hosted on GitHub Pages and uses fonts from Google Fonts. It has no cookies, analytics or tracking of its own. GitHub and Google may log basic request data such as IP addresses under their own privacy policies.

Children

Pagelift isn't directed at children and collects no data from anyone.

Changes

If this policy changes, we'll update this page and its effective date.
