Your tab

Captures pages behind a login

Pagelift reads the page from your own signed-in Chrome tab, so dashboards, admin panels, staging sites and localhost all work. The capture is saved as a file on your computer, and the Figma plugin has no network access at all.

To be fair: html.to.design's Chrome extension can also capture logged-in pages. Pagelift's difference is that it does this for free with no monthly limit, and without any server involved.

Trade-offs

When another tool is the better pick

Pagelift is young. Here is what it doesn't do yet, so you can decide before you install.

  • It isn't in the Figma Community or Chrome Web Store yet.You install both parts by hand from a zip. It takes about two minutes, but it's not one click.
  • It needs Figma's desktop app.Development plugins don't run in Figma in the browser. Until Pagelift is published, use the Mac or Windows app.
  • Chrome only, and no URL import.You capture from a Chrome tab. Other tools can fetch a public page from a URL pasted into Figma.
  • No hover states, dark mode or prototype links.You get what's on screen at capture time. html.to.design handles these.
  • Some CSS isn't carried over.Rotated or skewed elements are placed straight, decorative ::before and ::after content is skipped, and iframes become grey placeholders.
  • Fonts must be installed in Figma.Missing fonts are swapped for the closest match, and the import summary lists every swap.
  • Two steps instead of one.You download a .pagelift.json file in Chrome and drop it into Figma. Copy and paste works too.
  • Small team, best-effort support.There's no help desk or SLA. If something breaks, email us the JSON file and we'll look.
How it works

Capture, download, import

  1. Capture in Chrome

    Open the page, click the Pagelift icon, pick Desktop, Tablet or Mobile, and click Capture page. Pagelift scrolls the page first so lazy-loaded content appears.

  2. Download the file

    Click Download .json. The file holds the page's layout, text, styles and images, and stays on your computer.

  3. Import in Figma

    Run Pagelift in Figma, drop in the file, and click Import to Figma. Each viewport becomes its own frame, with named layers and local styles.

Install

Set up in about two minutes

Download and unzip pagelift.zip. It has two folders: extension and figma-plugin.

Chrome extension

  1. Go to chrome://extensions.
  2. Turn on Developer mode (top right).
  3. Click Load unpacked and choose the extension folder.
  4. Pin Pagelift — Capture to your toolbar.

Figma plugin

  1. Open the Figma desktop app.
  2. Go to Plugins → Development → Import plugin from manifest…
  3. Choose figma-plugin/manifest.json.
  4. Run it from Plugins → Development → Pagelift.

Questions

Good to know

Is it really free forever?

Yes. Pagelift runs entirely on your computer, so it costs us nothing when you use it. There's no account, no trial and no paid tier planned.

Where does my page data go?

Nowhere. The Chrome extension saves the capture as a file on your computer, and the Figma plugin reads that file. The plugin declares no network access, which Figma enforces. The only requests the extension makes are for the page's own images, from the sites already serving them to you. All the code is plain JavaScript in the zip, so you can read it.

Why does Chrome show "started debugging this browser"?

That's how Pagelift resizes the page to tablet and mobile widths. The bar disappears when the capture finishes. Tick Current window size only to skip resizing, and the bar won't appear.

Which plugin is Pagelift in my Figma menu?

The one tagged Development. Another plugin called "Web to Figma" is unrelated.

Can I capture someone else's website?

Pagelift captures whatever your browser shows. Use it for your own products, client work you're permitted to use, and reference. Respect copyright and trademarks.
