What you get

A website to Figma converter that keeps the structure

Pagelift reads the page the way the browser draws it, then rebuilds it with real Figma features instead of a flat screenshot.

  • Auto layout

    Rows and stacks become auto layout with the page's real padding, gaps and alignment. Overlapping content stays absolutely positioned, so nothing moves.

  • Hover states

    Buttons and links become components with Default and Hover variants, wired with "While hovering" so your prototype reacts like the site.

  • Dark mode

    Import a second set of frames in dark mode, for sites that follow the system setting. Light and dark sit in rows, ready to compare.

  • Prototype links

    Links between imported pages become click-throughs, #anchors scroll within the frame, and everything else opens its URL.

  • Colour and text styles

    Repeated colours and type become local styles, named under the site's domain and applied to every layer that uses them.

  • Every screen size

    Desktop, tablet and mobile frames from one import, with readable layer names like "Header", "Button · Sign up" and "H2 · Pricing".

  • Handles apps that build the page with JavaScript

How it works

From a web page to a Figma prototype in three steps

  1. Choose the page

    Paste URLs into the Pagelift plugin, or click Capture page in the Chrome extension for pages behind a login.

  2. Pick what to bring

    Choose Desktop, Tablet or Mobile, and turn on dark mode, hover states and images.

  3. Import to Figma

    Each screen size becomes a frame with named layers, auto layout, styles, hover variants and working links.

Install

Set up in about two minutes

Download and unzip pagelift.zip. It has an extension folder and a figma-plugin folder.

Figma plugin

  1. Open the Figma desktop app.
  2. Go to Plugins → Development → Import plugin from manifest…
  3. Choose figma-plugin/manifest.json.
  4. Run it from Plugins → Development → Pagelift.

Chrome extension for logged-in pages

  1. Go to chrome://extensions.
  2. Turn on Developer mode (top right).
  3. Click Load unpacked and choose the extension folder.
  4. Pin Pagelift — Capture to your toolbar.

Questions

Good to know

How do I convert a website to Figma for free?

Install the Pagelift Figma plugin, paste the website's URL and click Import to Figma. You get editable frames, auto layout, text, images and styles, with no account and no limit on imports. For pages behind a login, capture them with the Pagelift Chrome extension and drop the file into the plugin.

Is Pagelift a free alternative to html.to.design?

For many uses, yes. Both turn websites into editable Figma layers, import by URL, capture logged-in pages with a Chrome extension, and handle hover states, dark mode and multiple screen sizes. Pagelift is free with no import limit. html.to.design's free plan allows 10 imports every 30 days, and it's more polished, with one-click install and dedicated support. The comparison table above has the details.

Is it really free forever?

Yes. There's no account, no trial and no paid tier planned. Captures from the Chrome extension run entirely on your computer, and URL import uses a small proxy that costs us very little to run.

Where does my page data go?

With the Chrome extension, nowhere: the capture is saved as a file on your computer and the plugin reads that file. With URL import, the page and its files pass through Pagelift's proxy on Cloudflare so the plugin can read them. The proxy doesn't keep or log them. The privacy policy has the details.

Why do some pages come in incomplete from a URL?

URL import doesn't run the page's scripts, so apps that build the page with JavaScript, and sites that block automated visitors, may come in partly empty. Capture those with the Chrome extension instead, which reads the page exactly as your browser shows it.

Why does Chrome show "started debugging this browser"?

That's how the extension resizes the page to tablet and mobile widths, switches dark mode on and triggers hover states. The bar disappears when the capture finishes.

Which plugin is Pagelift in my Figma menu?

The one called Pagelift, tagged Development. A plugin called "Web to Figma" is unrelated.

Can I import someone else's website?

Pagelift imports whatever your browser can show. Use it for your own products, client work you're permitted to use, and reference. Respect copyright and trademarks.
